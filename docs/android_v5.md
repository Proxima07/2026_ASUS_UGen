# android_v5 手機原生錄音與記事本交接

日期：2026-10-12。來源差異包套用在 android_v4，搭配 backend_v6／web_v7。編譯好的 APK 可直接覆蓋安裝舊版，不需解除安裝或清除 App 資料。

## 原生錄音

網站語音首頁透過限定 HTTPS origin／主框架的橋接，請 APK 啟動 Android MediaRecorder。App 取得麥克風權限後錄成私有暫存 `.m4a` 音訊檔；按結束時收尾，再由 APK 的原生 HTTPS 用戶端將完整檔案送至 `POST /v1/audio?purpose=command`。

錄音不是即時串流，也不把裝置 bearer token 或私有檔案路徑交給 JavaScript。網站只取得錄音狀態及已驗證的後端工作結果，後續由既有 STT／Agent 流程處理。

開始前核對預期user／device與原生/me；獨立15秒啟動／權限期限。格式為MPEG_4／AAC、audio/mp4、96kbps、44.1kHz，App私有cacheDir/pending_voice中的隨機.m4a檔。每250ms回報經過時間與音量，停止後先釋放Recorder再上傳；180秒／8MiB到上限捨棄，沒有背景錄音服務。

成功、取消、錄音錯誤、上傳失敗及離開前景時，原生元件釋放麥克風與暫存檔。未送出音訊的取消不應建立後端工作；音訊已送達後，取消本頁不能撤回已收到的工作或已執行操作。

頁面離開／Activity銷毀也取消，App啟動清理孤立暫存。取消上傳會取消HTTP call，但伺服器可能已收到音訊；不自動重傳，也不說後端已撤回工作。

私有暫存檔位於 App 沙盒，不提供其他 App 任意讀取，也不列入備份。這不是另建永久音訊筆記庫；暫存音訊不應被描述為本程式已額外 AES 加密的檔案。對外傳輸使用 HTTPS，既有憑證驗證與拒絕明文政策保留。

## 手機自己的記事本 App

新增 `notes.create_native`。APK 從後端取得已驗證的標題與內容，顯示原生確認，再以 Android 常見的建立筆記 Intent 交給支援 App；無直接支援時使用文字分享選擇器。若手機沒有預設處理 App，系統可能讓使用者選擇記事本。

只有開啟／交接成功，回報 `handed_off`；使用者仍需在記事本 App 內確認儲存。沒有可處理的 App 會回 `unsupported`，不能宣稱「已存入記事本」。廠牌記事本是否接受此 Intent、標題或文字分享，仍需目標手機驗證。

Android 沒有所有記事本共用的內容提供者。此版不宣告通用的筆記讀取、搜尋、追加或修改能力，也不再把 APK 自建加密筆記區當成手機預設記事本。舊自建筆記檔與金鑰保留，沒有自動遷移、刪除或匯出；新版介面與能力握手不再提供其存取功能。

目標記事本 App 如何保存、雲端同步或分享內容，依該 App 的設定，不能視為後端 AES 加密範圍。後端 LLM／STT 與對話仍維持原本本地配置。

## 更新與驗收

使用 `android/releases/local-assistant-debug.apk` 覆蓋安裝。版本、APK 雜湊與簽署憑證見 `android/releases/README.md`。只安裝編譯包不需要先安裝中間版本；自行建置來源則依版本差異包順序覆蓋。

最終assembleDebug成功，versionName1.4／code5、min29／target35，APK v2簽章有效並與舊版同憑證。尚未在目標手機做覆蓋安裝、錄音或記事本實測。

網站與後端必須同時更新，才能使用新錄音橋接與記事本操作格式。現有 HTTPS origin、配對憑證與已配置的 cloudflared 可沿用；本版不要求改用專案 Tunnel 範例。

實機優先驗收：首次權限／拒絕後重試、短錄音／手動停止／取消、經過時間與紅色控制、離開 App 釋放麥克風、STT 接收 `.m4a`、網路錯誤可再次操作、記事本選擇器與儲存結果，以及兩組不同配對裝置筆記隔離。完整建置與測試結果見 `android/STATUS.md`；成功編譯不是目標手機錄音或記事本存入的實測。
