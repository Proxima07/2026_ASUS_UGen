# web_v3 語音首頁

日期：2026-10-12。本包是 web_v2 的差異更新，配合 backend_v3、android_v2。

## 使用流程

首頁只保留主要麥克風、語音逐字稿及 Agent 的回覆／狀態。點麥克風後說話，偵測到說話後停頓約兩秒會結束錄音並自動送出；也可再點一次結束。沒有偵測到語音時約十二秒停止並捨棄錄音。

錄音結束 → 私人 STT 轉錄 → 顯示逐字稿 → 自動送 Agent → 自動交給 APK → 手機原生確認 → 顯示實際結果。正常流程不用選擇功能、按上傳、轉錄、送出或網頁上的「在手機確認」。

原本的文字對話、平台筆記與錄音整理仍可從「其他工具」子頁開啟。首頁的筆記指令優先使用 APK 的加密手機筆記區；沒有手機能力或明確失敗時才用平台備援。多個同名聯絡人／筆記仍需釐清對象。

## 本地處理與執行規則

語音用 MediaRecorder 錄製，停頓偵測只在瀏覽器本地分析音量；不使用雲端 Web Speech API。音訊只送你配置的 STT。模型、轉錄服務由現有 backend/.env 配置，本次更新不覆蓋設定。

自動交接僅限當頁這次使用者主動錄音所建立的 request。每個 action ID 最多發送一次，聯絡人搜尋與筆記更新可依驗證結果接續；舊操作列表、重整或遲到回覆不會重新執行。登出、切到背景或切入其他工具會停止這次語音流程；回到畫面只查狀態，不自動重做。

原生權限與操作確認保留；網站不能越過手機確認，或自行傳任意 Intent。單段錄音上限三分鐘／10 MiB，逐字稿指令上限 8000 字元。沒有 Web Audio 支援時，需第二次點麥克風結束。

## 套用

1. 原後端先有 v1、v2，本次覆蓋 backend_v3 後重啟，沿用既有 cloudflared。
2. 網頁先有 web_v1、web_v2，在相同上層解壓 web_v3 覆蓋，瀏覽器 Ctrl+Shift+R。
3. 用 android_v2 包內 `android/releases/local-assistant-debug.apk` 更新安裝，再由 APK 打開同一 HTTPS 網站。
4. 一般瀏覽器可以測 STT／Agent 與平台備援；手機系統功能必須從已配對 APK 的網頁使用。

## 驗證與未完善

43 項 Node 測試已通過，涵蓋語音單次送出、冪等鍵、操作串接、訊息配對、取消／登出／背景、晚到權限與麥克風互斥。JavaScript 語法、DOM ID、本地資源引用及工具頁預設隱藏也已檢查。

此環境未提供瀏覽器視覺 QA；沒有執行 Chrome 或 WebView 真機驗收。停頓偵測門檻在吵雜環境需實機調整，對不同麥克風／語速不能假定等同 Google Assistant。沒有背景熱詞喚醒、持續監聽、TTS 或任意多意圖工作流。完整更新紀錄與限制見 web/CHANGELOG.md、web/STATUS.md。
