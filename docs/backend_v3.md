# backend_v3 語音與手機筆記優先

日期：2026-10-12。本包是 backend_v2 的差異更新，配合 web_v3 與 android_v2。

## 資料流

語音首頁錄音 → `/v1/audio?purpose=command` 原始音訊 → 私人 STT → transcribed 逐字稿 → `/v1/chat` → 本地 LLM 規劃 → APK 原生操作 → 真實結果回報。

轉錄專用模式不呼叫摘要 LLM、不自行建立操作，前端收到逐字稿後只送一次帶冪等鍵的指令。既有錄音整理使用預設 purpose=note，行為相容。

## 筆記策略

語音請求帶 `note_target=phone_first`、APK 握手能力提示；身分、裝置隔離、實際能力與確認仍由伺服器／APK 驗證。

- 新增：有 notes.save_local 能力時先交給手機，成功不另建平台筆記；明確失敗才改存平台。
- 搜尋：手機回傳最多 20 筆受限識別碼、標題與短預覽。
- 更新：notes.update 使用 query/content/mode/可選 title；明確一筆直接交接，多筆需選擇，不存在的對象不假裝更新完成。
- 備援：不支援、明確失敗或沒有手機能力時用平台；取消、逾時、不確定或未同步結果不回退。
- 追加：先固定最終內容再寫入，重送不會重複追加。

手機筆記是 APK 自己的加密本機筆記，不是任意廠牌預設記事 App。更新確認會顯示既有標題與短預覽。

## 套用與驗證

已先套用 backend_v1、backend_v2 後，在相同上層解壓本 ZIP。網頁先有 web_v1／web_v2，再套 web_v3；手機更新安裝 android_v2 的 APK。停止後端再覆蓋並重啟，既有 cloudflared 沿用。.env、資料庫與金鑰不由本包覆蓋，無資料表遷移。

68 項後端離線測試通過；包含 15 項手機筆記、防重送／備援／取消，以及 5 項指令轉錄測試。仍未在使用者實際 STT、LLM、Tunnel、手機完成端到端驗收。

## 目前限制

單次規劃一個主意圖，不是任意多指令工作流。時間或目標不明需澄清；平台筆記查找只涵蓋最近 200 筆。語音停止與自動送出由 web_v3 前景狀態機管理，不提供背景喚醒或持續監聽。完整狀態見 backend/STATUS.md。
