# Android 更新紀錄

## v2 — 2026-10-12

- 新增 notes.search_local，搜尋 APK 手機加密筆記並回傳受限的識別碼、標題與短預覽。
- 新增 notes.update_local，支援既有筆記的取代／追加，未指定標題時保留原標題；讀取與寫入在同一儲存鎖內進行。
- 配合 web_v3 語音首頁自動交接；原生確認、領取憑證、防重複及結果重送仍保留。
- 筆記參數補取僅限保存與分享，避免搜尋操作錯誤存取後端筆記。
- versionName 1.1、versionCode 2；最終 APK 已編譯並驗證簽章，簽署憑證與已交付 v1 相同。
- 本 ZIP 是相對 android_v1 的差異更新，附更新後的測試 APK。尚未真機驗收，詳見 STATUS.md。

## v1 — 2026-10-12

首次提供 `android_v1.zip`，保留 `local-assistant/android/` 目錄。

### 新增

- Kotlin 原生 HTTPS 配對、加密裝置 token、WebView 短效 cookie 登入。
- HTML／JavaScript 與原生橋接；僅指定來源及主框架可發出操作。
- 通訊錄搜尋、撥號、系統鬧鐘交接、日曆事件及提醒直接寫入。
- 自己的手機加密筆記與離線檢視，以及分享到其他記事 App。
- WebView 麥克風授權與音訊檔案選擇，搭配網站／後端完成錄音轉筆記。
- 原生操作確認、後端原子領取、加密執行收據、防重複及結果重送。
- 裝置停用、解除配對、登入／結果同步工具列。
- Gradle 建置設定、Manifest 權限、網路安全與備份排除設定。
- 可直接安裝的 Debug APK；最終來源建置與 APK v2 簽章驗證通過，實機行為尚待驗收。

### 邊界

- 模型與語音轉錄由私人後端執行，APK 不執行模型。
- 電話／鬧鐘／分享只回報畫面已開啟或交接，不宣稱外部 App 最後完成。
- Android 10 以上；iOS 不在此 APK 範圍。
- 需要 `backend_v2` 介接更新以及 `web_v1`。三段共用 HTTPS origin。
- 首次來源包為完整子專案；後續僅提供這個子專案修改的檔案。

### 未完成

實機、不同品牌、Cloudflare Access、mTLS、自動配對、正式簽章發布及當機後不確定操作的人工處理體驗，詳見 `STATUS.md`。
