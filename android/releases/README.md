# 測試 APK

`local-assistant-debug.apk` 由本版完整來源建置，APK v2 簽章驗證通過。Android 10 以上，套件 `com.proxima.localassistant`，版本 1.0／code 1。

SHA-256：`9bb4500022f1b382a5291b853254d330fda6cc02bc10695afd97acc67dfe7f4c`

可在 Android 手機下載或複製後，允許該檔案來源安裝並開啟。也可使用 `adb install -r releases/local-assistant-debug.apk`。實際手機尚未驗收；正式發布請改用自己的固定 release 簽章金鑰。

配對與使用步驟見上一層 `README.md`，建置及功能狀態見 `STATUS.md`。
