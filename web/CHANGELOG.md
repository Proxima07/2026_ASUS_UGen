# 網頁更新紀錄

## web_v10 — 2026-10-12

- 依web_v9實際診斷定位「清除舊語音指令」／clear_voice失敗；HTTP200表示Cookie API通過，頁面清理仍可能失敗。
- 修正VoiceFlow、CaptureSession與NativeCaptureSession預設計時函式被保存後，以元件物件作為接收者呼叫的TypeError。現在透過globalThis呼叫setTimeout／clearTimeout，保留測試注入能力。
- 原web_v9搭配嚴格接收者測試可重現HTTP200＋login_state_reset_failed／clear_voice；修正後同一路徑完成登入。
- 新增5項回歸：實際HTML登入清理、原生收聽與停止／取消／再錄、瀏覽器完整Blob收尾、權限取消後遲到stream、原生180秒期限與遲到上傳回覆隔離。
- 全部145項Node測試通過，包含原有140項。以前測試用的Node計時器／箭頭函式未檢查瀏覽器接收者，已補此差異；尚未實際WebView或目標手機驗收。
- 保留web_v9分階段診斷、身分核對、私人資料清理與登入期限。執行資源統一web-v10，須套用整個差異包。
- 本包相對web_v9，只更新網頁；backend_v6、android_v6、`.env`、配對資料及既有cloudflared保留，不需重建APK、重新配對或清快取。

## web_v9 — 2026-10-12

- 修正登入成功後清理舊狀態會自行更新 authGeneration，清理例外卻被當成過期回覆忽略的路徑；不再無限留下「正在驗證網頁登入 Cookie」。
- 登入驗證、舊狀態清理與新身分啟用分階段診斷；失敗停用私人操作與錄音，顯示具體階段及安全錯誤碼，保留已配對憑證。
- 清理失敗先撤銷權限、依序嘗試全部清理，並隱藏私人主畫面；成功清理及重新核對Cookie後才能恢復。
- 失敗自動展開診斷，保留已取得的HTTP200與追蹤ID；新增前端版本、目前階段、login_state_reset_failed／login_ui_failed安全代碼。
- 網站/me新增20秒等待上限，逾時顯示web_session_timeout；麥克風未授權時顯示目前連線警告，不一律要求重新配對。
- 加入登入等待期限與清理失敗回歸；失敗及重試不重播對話、錄音或已執行手機操作。
- 本地故障注入可重現舊版停住狀態；尚未確認截圖手機實際失敗元件，未在目標手機或公開站台完成驗收。
- 全部140項Node測試通過，包含6項新增回歸及原有134項；隨附HTML的DOM模擬與故障注入已檢查，未執行真實瀏覽器／WebView驗證。
- 本包相對 web_v8，只需覆蓋網頁；backend_v6、android_v6、`.env` 與既有 cloudflared 保留，無須重新配對或清 App 資料。

## web_v8 — 2026-10-12

- APK網頁先等hello／ready，再查同來源Cookie /me，不在原生session同步前提前認證。
- /me必須auth_kind=session，user_id與device_id完全等於APK；未核對不載入私人筆記／操作，不啟用錄音。
- Cookie401每頁至多自動hello一次，預算不因成功重置；另提供「重新建立登入」手動重試，合併未完成握手且有60秒期限。
- 遲到舊401／回覆不能覆蓋新登入。網路、HTML、代理與身分不一致不自動重新配對或無限同步。
- 將generic配對提示改成APK／網頁分階段狀態；新增摺疊HTTP／安全錯誤碼／request ID診斷，不顯示憑證。
- 全部134項Node測試通過，新增7項登入回歸；未在目標手機驗證實際Cookie問題。本版需android_v6，不變動backend_v6／共用協定。

## web_v7 — 2026-10-12

- APK語音首頁優先使用原生檔案錄音，綁定ready身分／recordingID；原生上傳後僅收job/trace回覆，接既有STT／Agent。
- 錄音開始才顯示收聽中與經過時間，紅色主麥克風／停止及紅色取消；等待與收尾可取消，錯誤／逾時不留錄音鎖。
- Chrome保留MediaRecorder完整Blob；15秒權限期限、取消與遲到stream清理，不需要STT串流。
- 身分變化／登出清除私人UI與API請求epoch，舊回覆不能恢復前一使用者的筆記。
- 手機記事本只用notes.create_native與真實handed_off，移除自建筆記能力；純瀏覽器不默默平台保存。
- STT草稿預設明確開啟手機記事本，另提供「保存到平台筆記」，平台列表標示平台位置。
- 更新web-v7全部runtime標記與載入檢查；全部127項Node測試通過。測試與未實機驗收範圍見STATUS.md。

## web_v6 — 2026-10-12

- 新增頁面共用 ConversationCoordinator；文字與語音使用後端 conversation_id／parent_request_id，追問後可直接補條件。
- 新增「新對話」，清除本頁訊息與關聯；不刪筆記、不重播歷史手機操作，對話 ID 不寫入永久瀏覽器儲存。
- 同頁送出鎖、上下文快照、人工重試／結果不明阻擋，以及登出／背景／遲到回覆世代保護。
- HTTP 200 failed request 仍保存有效對話 head；Actions 更新只呈現本頁接受的請求，舊列表不重新接入新話題。
- 新增 timer.create 能力與倒數長度顯示，純瀏覽器不假裝具有手機計時功能。
- 保留 v5 錄音控制／真實 STT 階段／追蹤與 v4 載入檢查；全執行資源更新 web-v6 revision。
- 117 項 Node 測試通過，含 25 項對話邊界與 5 項 API／timer 案例；語法、DOM、本地資源、CSP 及私人儲存檢查通過。
- 本地整合驗證會議追問接續、重送一次、新對話隔離、13 個資源與 timer action；未在實際模型、瀏覽器或手機驗收。
- 相對 web_v5 的差異包，完整流程需 backend_v5，倒數需要 android_v4。

## web_v5 — 2026-10-12

### 修正與新增

- 秒數獨立於 Web Audio 啟動，收聽中有明確文字、計時與可用音量回饋。
- 新增獨立「結束錄音並送出」及取消，停止即停收音並釋放該 session 的麥克風鎖；不再無限等待 stop 回呼。
- 停止錯誤、事件缺失、分析器關閉錯誤及舊 session 遲到事件有獨立收尾／失敗處理，不上傳未完整錄音，不干擾下一段。
- 上傳、已接收／排隊、真實 STT 狀態、轉錄文字、送出指令／等待回應、手機確認與結果分開顯示；不把 queued 假當正在 STT。
- 語音送 /chat 附 source_job_id，除錯區顯示 job／request／trace ID 對照 backend_v4 的事件紀錄。
- 發送後取消只停止本頁後續處理；遲到結果不能自動操作手機，不宣稱已取消伺服器工作。
- 保留 v4 獨立載入診斷、內建圖示與初始停用；全部執行資源升至一致 web-v5 revision。

### 使用與界線

- 來源包相對 web_v4；完整語音流程先更新 backend_v4，不需重裝 APK。
- 新版本文件、測試與目標手機界線見 docs/web_v5.md、STATUS.md。
- 音量回饋與停頓仍是本地分析，不是瀏覽器雲端 STT；真正轉錄由既有 .env 的本地服務處理。

### 驗證

- 87 項 Node 測試通過，包含 28 項 CaptureSession／實際 Voice／進階 Recorder 錄音邊界回歸。
- JavaScript 語法、DOM ID、同版本本地資源、CSP 與安全文字呈現檢查通過。
- 本地整合確認 12 個執行資源正常供應，mock 音訊 → STT → Agent 沿用同一 trace，模型只執行一次、9 個關鍵階段事件可對照。
- 尚未在實際 Chrome／WebView、麥克風、STT／LLM 與公開 Tunnel 驗收。

## web_v4 — 2026-10-12

### 修正

- 麥克風改用 HTML 內建 SVG，避免單一圖示檔 404 造成空白按鈕。
- 新增無其他模組依賴的 bootstrap；先檢查同來源 CSS／JavaScript 的 HTTP、MIME 與版本，再載入主程式。
- 首頁、CSS 與全部執行時 JavaScript 使用一致的 web-v4 revision，避免更新時混用新舊模組；本包包含更新後的 voice.js。
- 連線設定改為原生 HTML details，載入失敗仍可展開；bootstrap 可用時列出缺檔或版本錯誤。
- 完整啟動前，配對表單與功能保持停用；檔案檢查不消耗配對碼、不建立模型工作或手機操作。
- 失敗後重試採整頁重新載入，不會重新播放先前操作。
- 補充實際 WEB_DIR、新網域與既有 Tunnel 排查。已確認前版 ZIP 沒有漏掉兩個新增檔案，後端靜態路由無需變更。

### 範圍

- 本包為相對 web_v3 的差異更新；保留語音首頁、私人 STT／Agent、手機筆記優先與原生確認。
- 後端及 APK 沒有本次程式變更；完整語音功能仍需 backend_v3 與支援的 APK。
- 現場仍須把更新放到執行中後端實際使用的 web 目錄；前端容錯不會自動建立伺服器缺檔。
- 驗證結果見 STATUS.md，尚未在使用者實際公開站台或手機驗收。

### 驗證

- 50 項 Node 測試通過；新增載入失敗、HTTP 404、MIME／版本不符、同頁啟動一次、設定事件一次、完整模組圖與安全初始狀態檢查。
- 本地後端整合確認首頁、內建麥克風、初始停用及 11 個帶 revision 的執行資源全部 200，MIME、no-store／CSP 正確；健康檢查正常，未登入 API 回 401。
- 公開站台讀取在此環境無法取得；尚未確認現場 WEB_DIR、Cloudflare 或手機結果。

## web_v3 — 2026-10-12

### 變更

- 首頁改為大型麥克風、辨識文字、助理回覆與實際狀態；文字、平台筆記、錄音整理移到「其他工具」。
- 一次點擊開始說話，本地音量偵測在說完停頓約 2 秒後結束；第二次點擊仍可手動結束。
- 停止後自動上傳至指令專用本地 STT、自動送到 Agent，並自動交接此次語音的手機操作。正常流程沒有上傳／分析／執行按鈕。
- 語音以 phone_first 路由筆記，帶入原生握手能力；支援手機筆記新增、查詢、修改與同名候選選擇。手機能力不足時明確退回平台。
- 原生結果須匹配 message ID 與 action ID；每個 action 至多送一次，不自動重播歷史列表、不確定或已領取操作。
- 麥克風由語音／進階工具共用單一持有權；背景與登出期間取消授權，遲到的 STT、LLM、麥克風權限回覆都不恢復操作。
- 外部手機 App 回到前景只更新結果，不繼續自動操作。
- 保留 web_v2 fetch 接收者綁定修正。

### 驗證

- 43 項 Node 測試通過，包含語音流程與 14 項獨立邊界審查案例。
- JavaScript 語法、DOM ID、在地資源與安全文字顯示檢查通過。
- 尚未進行你的手機、麥克風／環境噪音、Cloudflare 網域與本地模型的端到端驗收。

### 依賴與限制

- 本版 /chat 欄位與 command 音訊端點需要 backend_v3。
- 手機新增／查詢／修改的實際能力以本次 APK 握手結果為準；舊 APK 可明確退回私人中樞。
- 本地音量門檻不是完整 VAD 模型；無 Web Audio 時需再點一次手動結束。
- 不支援喚醒詞、背景監聽、雲端語音、TTS 語音回覆、任意內建記事 App 資料庫存取。

## web_v2 — 2026-10-12

### 修正

- 修正 API 類別保存原生 fetch 卻以類別物件呼叫，造成瀏覽器接收者檢查失敗的問題。預設 fetch 現在綁定 globalThis，避免送出請求前的 TypeError 被顯示為「連線中斷」。
- 加入遵守瀏覽器接收者檢查的回歸案例；原版可重現 network_error，修正後可送出 API 請求。21 項 Node 測試通過。
- 補充既有 cloudflared 的整合、Cloudflare Web Analytics CSP 訊息、API 驗證與排錯步驟。

### 套用與限制

- 本 ZIP 為相對 web_v1 的差異更新，覆蓋同一個 local-assistant/web 後強制重新整理。
- 後端與 APK 沒有變更；CSP、同來源 API 與禁止重新導向的限制持續保留。
- 修正已經在接收者檢查回歸測試驗證，尚未在使用者的瀏覽器、Tunnel 或手機完成現場驗收。重新導向、Access 或網路失敗仍需要查實際 Network 請求。

## web_v1 — 2026-10-12

首次交付。ZIP 保留 `local-assistant/web/` 結構，沒有編譯依賴或外部前端資源。

### 新增

- 繁體中文手機優先介面：「對話」、「筆記」、「錄音整理」。
- 同來源瀏覽器配對、HttpOnly 登入、APK session 共用與原生能力握手。
- 文字指令、回答、手機操作內容、聯絡人候選選擇、取消與狀態更新。
- 模型回應以文字顯示；有狀態區分「已完成」「已開啟」「已交接」。
- 筆記搜尋、新增、編輯、再次確認後刪除；原生加密手機筆記與分享介接。
- 麥克風短錄音、原始音檔上傳、本地轉錄工作輪詢、草稿編輯保存。
- 逐字稿可帶入對話，再由使用者確認送出。
- 重試保留冪等鍵；登出後阻擋遲到的私人內容回填。
- Node 無依賴測試，以及 README、STATUS 和更新紀錄。

### 尚未涵蓋

- 完整持久化聊天歷史、離線模式、即時字幕、背景錄音。
- 在瀏覽器直接讀取手機通訊錄或直接設定系統鬧鐘。
- 對任意手機內建記事 App 的直接寫入。
- 手機、後端與模型之間的應用層端對端加密。
- Android 真機、iPhone、Cloudflare 實際網域的端到端測試。

### 介接依賴

- 基礎功能對接 backend_v1。
- 筆記 → 手機保存／分享的按鈕需要本次 backend_v2。
- 原生功能需要 android_v1 APK 來源所建置的 App。
