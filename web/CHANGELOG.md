# 網頁更新紀錄

## web_v2 — 2026-10-12

### 修正

- 修正 API 類別保存原生 fetch 卻以類別物件呼叫，造成瀏覽器接收者檢查失敗的問題。預設 fetch 現在綁定 globalThis，避免送出請求前的 TypeError 被顯示為「連線中斷」。
- 加入遵守瀏覽器接收者檢查的回歸案例；原版可重現 network_error，修正後可送出 API 請求。21 項 Node 測試通過。
- 補充既有 cloudflared 的整合、Cloudflare Web Analytics CSP 訊息、API 驗證與排錯步驟。

### 套用與限制

- 本 ZIP 為相對 web_v1 的差異更新，覆蓋同一個 local-assistant/web 後強制重新整理。
- 後端與 APK 沒有變更；CSP、同來源 API 與禁止重新導向的限制持續保留。
- 修正已經在接收者檢查回歸測試驗證，尚未在使用者的瀏覽器、Tunnel 或手機完成現場驗收。重新導向、Access 或網路失敗仍需要查實際 Network 請求。

## web_v1 — 2026-10-12

首次交付。ZIP 保留 `local-assistant/web/` 結構，沒有編譯依賴或外部前端資源。

### 新增

- 繁體中文手機優先介面：「對話」、「筆記」、「錄音整理」。
- 同來源瀏覽器配對、HttpOnly 登入、APK session 共用與原生能力握手。
- 文字指令、回答、手機操作內容、聯絡人候選選擇、取消與狀態更新。
- 模型回應以文字顯示；有狀態區分「已完成」「已開啟」「已交接」。
- 筆記搜尋、新增、編輯、再次確認後刪除；原生加密手機筆記與分享介接。
- 麥克風短錄音、原始音檔上傳、本地轉錄工作輪詢、草稿編輯保存。
- 逐字稿可帶入對話，再由使用者確認送出。
- 重試保留冪等鍵；登出後阻擋遲到的私人內容回填。
- Node 無依賴測試，以及 README、STATUS 和更新紀錄。

### 尚未涵蓋

- 完整持久化聊天歷史、離線模式、即時字幕、背景錄音。
- 在瀏覽器直接讀取手機通訊錄或直接設定系統鬧鐘。
- 對任意手機內建記事 App 的直接寫入。
- 手機、後端與模型之間的應用層端對端加密。
- Android 真機、iPhone、Cloudflare 實際網域的端到端測試。

### 介接依賴

- 基礎功能對接 backend_v1。
- 筆記 → 手機保存／分享的按鈕需要本次 backend_v2。
- 原生功能需要 android_v1 APK 來源所建置的 App。
