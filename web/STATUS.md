# 網頁功能與完成狀態 — web_v5

更新日期：2026-10-12。

## v5 錄音控制與處理階段

| 項目 | 實作範圍 | 仍須目標設備確認 |
|---|---|---|
| 明確收聽及獨立計時 | 不等待 AudioContext.resume | 手機麥克風、視覺與秒數 |
| 手動結束／取消 | 獨立按鈕、停止收音、session 鎖釋放與收尾 | Chrome／WebView 的實際 stop 事件 |
| 錄音錯誤復原 | stop／context 錯誤與遲到回呼不得卡住或誤送 | 目標裝置音訊供應者 |
| 上傳與後端接收 | 成功取得 job ID 才宣稱已接收 | 實際 Tunnel／後端回應 |
| 真實 STT 階段 | queued／transcribing／transcribed 分開 | 真實本地轉錄服務、等待時間 |
| 指令送出與結果 | 等待 /chat 回應與 request ID 分開 | 模型速度、APK 原生確認 |
| 除錯對照 | job／request／trace ID，需 backend_v4 | PyCharm Console 與設備時間 |
| 取消後不自動操作 | 本頁流程停止、遲到結果忽略 | 後端已收到的工作可能仍完成 |

本版回歸與整合驗證結果見末尾。程式測試不能代替手機麥克風、真實 STT／LLM 與公開網域驗收。

## 建議真機驗收

1. 一般瀏覽器完成配對 → 建立／編輯／刪除一筆筆記 → 登出後頁面沒有私人內容。
2. APK 配對 → 網站握手完成 →「查媽媽的電話」顯示候選結果；同名者不自動選錯。
3. 「打電話給媽媽」→ 原生授權與確認 → 電話畫面含正確號碼；網站只表示已開啟。
4. 「設定七點鬧鐘」→ 顯示原生確認 → 開啟時鐘 → 人工確認鬧鐘設定；不宣稱已響鈴。
5. 「明天下午三點開會一小時」→ 日曆操作 → 確認實際事件時間與提醒。
6. 錄音 20–30 秒 → 播放 → 本地轉錄與整理 → 修正 → 保存到筆記。
7. 在摘要 API 不可用時，逐字稿可留在編輯區與手動保存；STT 未設定時有清楚錯誤。
8. 測試麥克風拒絕、通訊錄拒絕、網路斷線、session 到期、過期 action 與後端重啟。

## 目前界線

這個版本是可對接 API 的實作，沒有模擬私人模型的假成功回答。Node 測試與原始碼檢查已經進行；尚未以你的 Pi、模型端點、Cloudflare 網域與 Android 手機做端到端展示。錄音工作 ID 未永久保存於瀏覽器，處理途中重新整理後不會自動恢復那個錄音工作。

## v3 優先真機驗收

1. APK 配對 → 首頁點一下 → 說「幫我記下明天開會帶報告」→ 停頓 → 本地轉錄／Agent → 原生確認 → 顯示保存位置是手機。
2. 說「找出開會的筆記」→ 手機搜尋授權與結果；多筆修改時可選對應筆記。
3. 說「幫我打電話給媽媽」→ 通訊錄搜尋 → 同名時選擇 → 撥號確認；網站只回報已開啟。
4. 測試不說話 12 秒、輕聲、背景音、連續句子；確認停頓門檻適合展示手機。
5. 在等待麥克風權限、STT 或 LLM 時切換背景／登出，確認不再出現新的手機操作。
6. 電話／日曆 App 返回後，只更新已記錄結果；重新整理不重播先前操作。

## v4 已執行的驗證

- 50 項 Node 測試通過。保留 v3 語音與執行邊界測試，新增缺檔／HTTP／MIME／revision 阻擋、同頁只啟動一次、設定事件只綁一次、初始配對安全停用及完整模組依賴圖驗證。
- 唯讀審查通過：bootstrap 無其他模組依賴；檢查只使用固定同來源靜態檔 GET；失敗不載入主程式；配對與手機操作不會被檢查觸發；重新載入不重播工作。
- 本地後端 TestClient 整合通過：首頁、HTML 麥克風 SVG、兩個初始 disabled fieldset、11 個帶 revision 的 CSS／JavaScript、HTTP 200、MIME、no-store／原 CSP。另確認 /health 正常、未登入 /v1/auth/me 為 401。
- 後端既有路由已另行確認：啟動後新增檔立即可讀，404 也有 no-store，錯誤 Host 回 400。後端沒有本次程式修改。
- 使用者新公開網址與兩個資源的遠端讀取在此環境無法取得內容。沒有把工具讀取失敗當作站台中斷，也未透過真實 Chrome／WebView 確認部署修復。

仍須由目標設備確認：更新落在實際 WEB_DIR、公開路徑不再 404、頁面不再提示缺檔／混版、配對及語音正常。若本機 200 而公開 404，繼續檢查既有 Tunnel 與代理設定。

尚未在使用者實際 Chrome／Android WebView、麥克風硬體、本地 STT／LLM 或公開 Tunnel 做端到端驗收。若裝置 stop 收尾超過 3 秒，本版會回報未送出並允許重新錄音；不以不完整資料假裝成功。
