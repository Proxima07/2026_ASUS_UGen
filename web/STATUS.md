# 網頁功能與完成狀態 — web_v3

更新日期：2026-10-12。

## v3 語音首頁與當前完成程度

| 功能 | 本版狀態 | 尚需驗收／限制 |
|---|---|---|
| 首頁大型麥克風，其他工具收納 | 已實作 | 尚未在你的 Android WebView 做視覺驗收 |
| 本地停頓偵測，自動結束 | 已實作、門檻測試通過 | 2 秒停頓；噪音、輕聲與增益需真機調整 |
| 指令錄音 → STT → Agent | 自動鏈接已實作 | 需 backend_v3，模型與 STT 均由私人設備提供 |
| 此次語音 → 原生操作 | 自動交接、每 action 至多一次 | 實際手機操作仍有原生確認與權限 |
| 手機筆記優先 | 新增／搜尋／修改已介接 | 僅 APK 自己的加密筆記；無能力時平台 fallback |
| 歧義對象選擇 | 同名電話／多筆筆記候選 | 只在歧義時需要選擇；不選操作類型 |
| 背景／登出取消 | 已實作、遲到回應測試通過 | 已上傳工作可在後端完成，但不再觸發手機 |
| 外部 App 返回首頁 | 只更新實際結果 | 暫停的流程不自動繼續／重播 |
| 無語音捨棄／錄音上限 | 已實作與測試 | 12 秒無語音；180 秒、10 MiB |
| 無 Web Audio 裝置 | 手動結束備援 | 需再點麥克風；不是自動停頓 |
| 原生訊息相關性 | 已實作與測試 | 必須同時匹配送出訊息與操作 ID |
| v3 全套網頁測試 | 43 項 Node 通過 | 非真機、非瀏覽器視覺或模型能力驗證 |

首頁錄音不會先建立摘要筆記。語音筆記會顯示保存位置；進階工具中的「我的筆記」仍是平台筆記列表，不會自動下載手機整份資料庫。語音目前採單次指令，LLM 發出澄清時，下一段請完整重述條件；沒有宣稱已完成持久化多輪對話記憶。

## 建議真機驗收

1. 一般瀏覽器完成配對 → 建立／編輯／刪除一筆筆記 → 登出後頁面沒有私人內容。
2. APK 配對 → 網站握手完成 →「查媽媽的電話」顯示候選結果；同名者不自動選錯。
3. 「打電話給媽媽」→ 原生授權與確認 → 電話畫面含正確號碼；網站只表示已開啟。
4. 「設定七點鬧鐘」→ 顯示原生確認 → 開啟時鐘 → 人工確認鬧鐘設定；不宣稱已響鈴。
5. 「明天下午三點開會一小時」→ 日曆操作 → 確認實際事件時間與提醒。
6. 錄音 20–30 秒 → 播放 → 本地轉錄與整理 → 修正 → 保存到筆記。
7. 在摘要 API 不可用時，逐字稿可留在編輯區與手動保存；STT 未設定時有清楚錯誤。
8. 測試麥克風拒絕、通訊錄拒絕、網路斷線、session 到期、過期 action 與後端重啟。

## 目前界線

這個版本是可對接 API 的實作，沒有模擬私人模型的假成功回答。Node 測試與原始碼檢查已經進行；尚未以你的 Pi、模型端點、Cloudflare 網域與 Android 手機做端到端展示。錄音工作 ID 未永久保存於瀏覽器，處理途中重新整理後不會自動恢復那個錄音工作。

## v3 優先真機驗收

1. APK 配對 → 首頁點一下 → 說「幫我記下明天開會帶報告」→ 停頓 → 本地轉錄／Agent → 原生確認 → 顯示保存位置是手機。
2. 說「找出開會的筆記」→ 手機搜尋授權與結果；多筆修改時可選對應筆記。
3. 說「幫我打電話給媽媽」→ 通訊錄搜尋 → 同名時選擇 → 撥號確認；網站只回報已開啟。
4. 測試不說話 12 秒、輕聲、背景音、連續句子；確認停頓門檻適合展示手機。
5. 在等待麥克風權限、STT 或 LLM 時切換背景／登出，確認不再出現新的手機操作。
6. 電話／日曆 App 返回後，只更新已記錄結果；重新整理不重播先前操作。
