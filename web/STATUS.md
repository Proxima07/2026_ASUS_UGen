## 建議真機驗收

1. 一般瀏覽器完成配對 → 建立／編輯／刪除一筆筆記 → 登出後頁面沒有私人內容。
2. APK 配對 → 網站握手完成 →「查媽媽的電話」顯示候選結果；同名者不自動選錯。
3. 「打電話給媽媽」→ 原生授權與確認 → 電話畫面含正確號碼；網站只表示已開啟。
4. 「設定七點鬧鐘」→ 顯示原生確認 → 開啟時鐘 → 人工確認鬧鐘設定；不宣稱已響鈴。
5. 「明天下午三點開會一小時」→ 日曆操作 → 確認實際事件時間與提醒。
6. 錄音 20–30 秒 → 播放 → 本地轉錄與整理 → 修正 → 保存到筆記。
7. 在摘要 API 不可用時，逐字稿可留在編輯區與手動保存；STT 未設定時有清楚錯誤。
8. 測試麥克風拒絕、通訊錄拒絕、網路斷線、session 到期、過期 action 與後端重啟。

## 目前界線

這個版本是可對接 API 的實作，沒有模擬私人模型的假成功回答。Node 測試與原始碼檢查已經進行；尚未以你的 Pi、模型端點、Cloudflare 網域與 Android 手機做端到端展示。錄音工作 ID 未永久保存於瀏覽器，處理途中重新整理後不會自動恢復那個錄音工作。
