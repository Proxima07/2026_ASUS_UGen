# backend_v3 功能狀態

更新日期：2026-10-12。Python 中樞第三版與 web_v3／android_v2 分包交付；手機行為尚未完成實機驗收。

| 項目 | 本版狀態 | 目前範圍與下一步 |
|---|---|---|
| OpenAI 相容 LLM | 已提供 | 設定自訂 URL／模型；實際模型輸出品質需在你的主機驗證 |
| 本地上下文與筆記 | 已提供 | SQLite 保存敏感欄位加密；不是向量搜尋／長期偏好學習的完整產品 |
| 身分與配對 | 已提供 | 一次性配對碼、裝置 token、session；web_v1／android_v1 有手動配對介面，尚無 QR code |
| 操作規劃與確認 | 已提供 | 操作白名單、參數檢查、確認／結果流程；日期或對象不明確需澄清 |
| 聯絡人搜尋／撥號 | 後端流程已提供 | android_v1 已實作通訊錄與 `ACTION_DIAL`，需實機驗證 |
| 鬧鐘 | 後端流程已提供 | 手機端時鐘 Intent 與各品牌相容性尚未驗證 |
| 日曆 | 後端流程已提供 | android_v1 已實作權限、日曆選擇與直接寫入，需實機驗證 |
| 手機記事本 | 後端筆記與原生操作 API 已提供 | APK 可另存自己的加密筆記或交給分享 App；各品牌記事 App 需另行實測 |
| 語音自動指令 | 指令專用轉錄已提供 | 不先摘要，轉錄後由前端送 Agent；停頓偵測與手機前景需真機驗證 |
| 手機筆記優先 | 已提供 | 支援手機搜尋／取代／追加；只有明確失敗才改用平台，取消或不確定結果不回退 |
| 錄音轉筆記 | 可選端點介接 | 不內附 STT 服務；未配置 `STT_BASE_URL` 時功能停用 |
| HTTPS 與 Tunnel | 已提供部署範例 | 網域／憑證／Tunnel 由你部署；Cloudflare edge 可處理解密後內容 |
| 網頁／APK | 分包交付 | 使用 web_v1／android_v1 的程式與版本文件；手機行為須實機驗證 |
| 原生實機驗收 | 未執行 | 固定一支 Android 裝置驗證權限、背景／切換畫面與結果狀態 |
| 多人完整隔離 | 未提供 | 配對裝置共用預設使用者的筆記；請求與操作綁定裝置，不能當作多人獨立帳號入口 |
| 背景長任務可靠度 | PoC 範圍 | 原始錄音僅保留記憶體；重啟中斷需重新上傳，不是持久任務佇列 |
| 本地資料備份與輪替 | 尚待完善 | 金鑰分離備份、資料保留週期與復原操作需另定 |

## 驗收應分開看

1. **程式測試**：68 項離線測試已通過，使用 fake／mock 模型驗證 API、操作防重複、裝置隔離、加密讀寫、請求容量、模型傳輸、手機筆記優先、指令轉錄與網頁掛載。實測環境為 Python 3.12；尚未在 Pi、Windows 或實際模型上驗證。單獨解壓後端而未安裝網頁時，網頁掛載測試會略過。
2. **你的模型**：確認 OpenAI 相容程度、繁體中文日期解析與參數品質。
3. **實際部署**：Pi、模型主機、CA、Tunnel 與網域是否可連接。
4. **手機**：APK 權限、通訊錄、時鐘、日曆與第三方記事 App。

前一項通過，不會自動證明後三項已完成。展示時只宣稱已實際驗證的範圍。

本版單段話語規劃一個主意圖，通訊錄撥號與筆記修改可由確定性流程接續操作；不是任意多步工作流。平台筆記備援搜尋僅檢查最近 200 筆，未提供完整歷史分頁搜尋。多個可能對象仍需澄清。
